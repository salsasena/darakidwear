# DARA KIDS WEAR

Korean-inspired aesthetic kidswear storefront with butter-yellow branding.

## Included
- Responsive landing page
- Product catalog with 8 original SVG product illustrations
- Search + category filters
- Product order modal with size/color/quantity
- Add-to-bag cart
- WhatsApp ordering
- New arrivals, story, benefits, FAQ and footer
- No external product image files are required

## WhatsApp
The demo number is `+62 812-3456-7890`.
Change `6281234567890` in `script.js` to your real WhatsApp number.

## Run
Open `index.html` in a browser.

## Image licensing
The product illustrations in `assets/` are original SVG artwork created for this template, so the package does not depend on third-party stock photos.
